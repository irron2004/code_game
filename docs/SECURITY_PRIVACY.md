
# 보안/개인정보

## 원칙
- PII 미수집(초기), 레벨/설정은 로컬 저장(localStorage)
- 광고·사용자 입력·맵 원본 외부 전송 금지. 비식별 제품 텔레메트리만 아래 계약에 따라 전송

## 아동/교육 고려
- 광고/추적 금지
- 계정 기능 도입 시 COPPA/GDPR-K 대응(나이/부모 동의/데이터 정정·삭제 절차)

## 데이터 보관(로컬 키 예)
- `algame:v1:level:last`
- `algame:v1:settings`

## 텔레메트리 수집
- `telemetry.js`는 익명 세션/디바이스 ID(난수)를 생성하여 `/v1/events`로 전송하며, 내용은 알고리즘 실행 요약·규칙 변경·경로 없음 진단 등 **비식별 통계**만 포함합니다.
- 서버(`server.js`)는 JWT(Bearer) + RateLimit + Origin 화이트리스트로 보호하며, Postgres(JSONB)에 저장된 원시 이벤트는 **30~90일 보관 후 집계**를 추천합니다.
- 맵 원본/사용자 입력/PII는 전송하지 않으며, 실패 시 이벤트는 드롭되거나 로컬 로그로만 남습니다.
