# UX 가이드 (어린이 친화)

## 1. 언어
- 쉬운 단어: “재생”, “멈추기”, “한 칸씩”, “규칙 바꾸기”
- 툴팁: “대각선을 켜면, 대각선으로도 움직여요!”

## 2. 시각
- 색 대비 확보(색약 고려)
- 현재 노드(따뜻한색), 경로(보라, 굵기 2~3px)
- 격자선 ON 기본

## 3. 조작
- 마우스/터치 드래그 동일 동작
- 버튼 ≥ 40px, 여백 8~12px
- 되돌리기(리셋)와 경고 메시지

### 온보딩 패널
- 첫 방문 1회 노출, `localStorage.onboardingDismissed=true`로 재방문 억제
- 키보드 단축키 4개 강조: Space, N, R, 1~6
- “다시 보지 않기” 체크 + “시작하기” 주요 행동 버튼

### 튜토리얼 모달
- 최대 3단계, 각 단계 2~3줄 설명 + bullet 2개 이하
- `이전/다음 단계` 버튼, 마지막에는 “완료”로 copy 변경
- 모달 열릴 때 포커스 트랩, ESC/배경 클릭으로 닫기

### “경로 없음” 토스트
- 실패 1초 내 자동 노출, 6.5초 후 자동 닫힘(hover/focus 시 타이머 일시정지)
- 메시지: 성공 옵션 존재 시 “길이 막혔어요 / 아래 중 하나를 바꾸면 …”
- 버튼: 최대 3개, 성공 옵션은 연두색, 현재 적용 중인 규칙은 “(적용됨)” 라벨링
- 닫힌 뒤 패널의 “도움 받기”로 재호출 가능

## 4. 접근성
- ARIA 라벨 예: “재생 버튼”, “속도 슬라이더(초당 프레임)”
- 키보드 숏컷: Space(재생/정지), N(한 스텝), R(리셋), 1~6(브러시)

## 5. 교육 피드백
- 경로 없음: “벽 때문에 막혔어요(빨간 부분)”
- 가중치 on: “숲은 2, 모래는 3으로 계산해요”
